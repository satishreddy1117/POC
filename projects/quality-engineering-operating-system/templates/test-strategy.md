# Generic test strategy

## Objective

State the business outcome the release must protect.

## Risk profile

| Risk | Likelihood | Impact | Mitigation | Evidence |
| --- | --- | --- | --- | --- |
| Example risk | Medium | High | API and journey coverage | Linked result |

## Test layers

- unit and component checks for fast feedback;
- API and contract checks for service behavior;
- integration checks for dependency boundaries;
- critical-journey checks for user outcomes;
- accessibility, security, performance, and resilience checks based on risk.

## Exit criteria

Document measurable pass thresholds, known gaps, waiver owner, waiver expiry, and post-release monitoring.
