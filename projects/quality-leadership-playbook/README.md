# Quality Leadership Playbook

Reusable artifacts and small decision helpers for communicating quality risk to technical and organizational audiences.

## Included

- decision-log validation and action tracking;
- one-page meeting brief generation;
- quality metric snapshots with status bands;
- strategy, risk-review, go/no-go, metrics, and responsibility templates.

## Run it

```bash
npm run leadership:playbook
node --test projects/quality-leadership-playbook/test
```

The playbook is designed to make quality discussions concrete: what is known, what is uncertain, what decision is needed, who owns it, and when it must be revisited.
