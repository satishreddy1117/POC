# ADR-001: Use generic synthetic scenarios

## Status

Accepted

## Decision

All portfolio examples use fictional system names, deterministic fixtures, and synthetic records. No current project names, customer details, internal identifiers, or production-like secrets are included.

## Rationale

The portfolio should demonstrate transferable engineering judgment without exposing proprietary information or making claims about a real system.

## Consequences

- Examples are safe to publish publicly.
- Metrics are illustrative rather than production claims.
- Readers can run every scenario locally.
